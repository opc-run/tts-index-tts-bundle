# tools/ — 便携工具目录（已预建）

本目录存放安装脚本自动下载的**便携版工具**，随整合包携带：不写系统 PATH、不注册系统，删除整合包即彻底移除。

| 子目录 | 内容 | 何时生成 |
|---|---|---|
| `tools/uv/` | 便携版 uv（官方安装脚本，`UV_UNMANAGED_INSTALL=1`） | 宿主机缺 uv 时自动下载 |
| `tools/ffmpeg/` | 便携版 ffmpeg（BtbN gpl 构建，仅 Windows） | 宿主机缺 ffmpeg 时自动下载 |

## 说明

- 目录已随整合包**预建**，无需手动创建；安装脚本检测到缺工具时自动下载填充。
- 宿主机已装有 uv / ffmpeg 时，本目录会保持为空（脚本直接复用系统工具）。
- **重复运行不会重复下载**：上次安装下载的便携 ffmpeg 会留在本目录，下次安装直接复用（uv 同理，便携版安装在 `tools/uv/`）。
- 删除本目录不影响宿主机，但下次安装缺工具时会重新下载。
